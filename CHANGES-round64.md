# Round 64 — Staff theme reaction, one-click push, and the help desk

- Hazard map totals (Hazard areas, Shown to the public, Shelters open, People checked in) now use the dark card when dark mode is on. Those tiles were hardcoded white.
- Case-file headers no longer stay white in dark mode. Incident Details, Incident Location, Attachments, Paper forms, Activity, and Reporter Details use the dark card, so the title and the tracking line stay readable. The same header treatment covers admin, agency, and personnel.
- The scan-document line “Lay the document flat inside the frame, then capture.” stays readable on the camera dialog. It was light type on a light blue bar.
- Outline buttons, their icons, and the modal close mark pick up a light color in dark mode.
- Turning dark mode off on Appearance restores dark type immediately. The page no longer waits for Save Settings before the light-mode text comes back. The color theme still applies while dark mode is on.
- Push notifications turn on with one click. After the browser allows notifications, this account is subscribed in that same click.
- Staff Support Center (admin, agency, and personnel) uses the same form as the public support page: navy section headers, teal category label and submit button, the same category tiles, timeline, and tips, on the same graph-paper background. The “Let’s get you to the right place” banner stays on the public page only. Dark mode uses the public support page’s dark form.
